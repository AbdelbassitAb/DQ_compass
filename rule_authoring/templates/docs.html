{{ schema.FIELD_HELP['threshold_pct'] }}

Validation checks applied before saving

Blocking errors — the rule is not saved:

  • rule_id required, unique, format letter + [A-Za-z0-9_-] (2–20)
  • all required text fields present and within length bounds
  • control_type / severity / frequency in the allowed values
  • dataset_scope (and the reference dataset) declared in datasets_config.yaml
  • referenced columns actually exist in the dataset (checked on a sample)
  • params consistent with the type; threshold_pct in [0, 100]

Warnings — saved but flagged: High control at low frequency; duplicate logic; high tolerance on a High control; self-reference; overly permissive regex.

Audit log

Every create / update / delete / (de)activate / retire / purge / rename is written to catalogue_changelog.jsonl or data_sources_changelog.jsonl (append-only) with the editor, the UTC timestamp, the before/after and the SHA-256 hash before and after. See Activity.
