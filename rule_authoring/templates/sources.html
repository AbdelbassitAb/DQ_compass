Delete policy

Retire is a reversible soft delete — the source is kept, dependent rules are deactivated and can be brought back. Purge removes the source for good; rule definitions are never deleted, only deactivated. Rename rewrites dataset_scope / ref_dataset_scope on every dependent rule in one logged transaction. A rule pointing at a missing or retired source does not crash the engine — it produces an ERROR record and the run continues.
